# 结果页归类与重构

面向合规与法务审核人员。目标是辨认待复核项、核对证据、执行补证与归档，不把图片识别等同于合规通过。

## 信息定义

- 观察：从照片获得的可见信息，不证明认证有效。
- 检查：选定品类要求的逐项覆盖状态，包含未评估项。
- 发现：疑点、确定问题或待证据事项；不直接等于一项用户待办。
- 资料请求：按需要的照片或文档合并的补证任务，与发现数量分开。
- 引用：对应来源和核验状态；条款定位不等于逐字核验。

## 展示归属

| 区域 | 内容 | 默认状态 |
| --- | --- | --- |
| 概览 | 产品、市场、版本、审核状态、统计口径 | 精简常显 |
| 审核清单 | 优先复核、全部检查、已观察且无疑点 | 默认优先复核 |
| 证据核对 | 图片、观察点、风险、来源 | 清单点击联动，按需进入 |
| 报告与处置 | 补证、修订、排期、导出、报告全文 | 全文折叠 |

重复的阅读顺序大卡片、巨型产品标题、重复补证列表、装饰性报告样张移除。原有风险、图像定位、引用和修订功能保留。旧锚点进入对应区域并展开必要内容。

## 验收

首屏能够识别产品和审核状态；优先复核项可定位到图像；资料请求只在处置区域列出；引用、导出与修订入口可达；键盘能够切换分类；筛选不把已观察称为通过。
