# 火鹰合规 (Blaze Hawks) - 产品需求文档 (PRD)

## 1. 产品愿景

### 核心价值
**在产品上架海外市场前，通过 AI 视觉分析快速识别合规风险点**

> "想出海？先烧毁。" —— 用 AI 的火眼金睛，先把风险"烧掉"

### 目标用户画像
| 角色 | 痛点 | 需求 |
|------|------|------|
| 跨境电商卖家 | 不了解目的地法规，上架后被下架/罚款 | 快速自查，降低风险 |
| 品牌合规负责人 | 人工审核图片效率低，遗漏风险 | 自动化扫描，提升效率 |
| 工厂外贸业务 | 不确定产品图片是否合规 | 一键检测，即时反馈 |

### 成功标准
- 用户上传图片后，5 分钟内获得风险报告
- 覆盖欧盟 CE、美国 FCC、英国 UKCA 等主流市场法规
- 风险识别准确率 > 85%

## 2. 产品功能

### 2.1 图片上传 (P0)

**功能描述**
用户可上传 1-8 张产品图片，支持 JPG/PNG/WebP 格式

**用户流程**
```
1. 访问 /upload 页面
2. 点击文件选择器，选择图片
3. (可选) 选择产品类别: 电子产品/家电/3C/玩具/家居/其他
4. (可选) 选择目标市场: EU/US/UK (默认 EU+US)
5. 点击"提交并开始扫描"
6. 跳转到扫描中页面
```

**验收标准**

| 整改清单 | 待办事项、所需材料、预计费用、建议实验室 |
| 法规引用 | 法规代码、名称、来源链接、市场 |

## 4. 数据模型

### 4.1 ScanResult (扫描结果)
```typescript
interface ScanResult {
  sessionId: string;           // 唯一会话 ID
  scanTime: string;            // 扫描时间 (ISO)
  productCategory: string;     // 产品类别
  productName?: string;        // 产品名称 (AI 识别)
  targetMarkets: Market[];    // 目标市场
  complianceScore: number;    // 合规得分 (0-100)
  scoreGrade: ScoreGrade;      // 等级 (A/B/C/D)
  images: ImageAsset[];        // 图片列表
  riskPoints: RiskPoint[];    // 风险点列表
  checklist: ChecklistItem[]; // 整改清单
  generatedAt: string;        // 生成时间
  modelInfo?: {               // AI 模型信息
    visionProvider: string;
    latencyMs: number;
  };
}
```

### 4.2 评分规则
| 等级 | 分数范围 | 含义 |
|------|----------|------|
| A | 90-100 | 低风险，可直接上架 |
| B | 70-89 | 轻微风险，需小整改 |
| C | 50-69 | 中等风险，需整改后上架 |
| D | 0-49 | 高风险，不建议上架 |

## 5. API 设计

### 5.1 启动扫描 POST /api/scan

**请求**
```
POST /api/scan
Content-Type: multipart/form-data

images: File[] (1-8 张)
category: string (可选，默认 "electronics")
markets: string (可选，默认 "EU,US")
```

**响应 202**
```json
{
  "sessionId": "scan_01JXXXXX",
  "status": "processing",
  "pollUrl": "/api/scan/scan_01JXXXXX"
}
```

**错误 400**
```json
{
  "error": {
    "code": "BAD_INPUT",
    "message": "请至少上传 1 张图片"
  }
}
```

### 5.2 查询状态 GET /api/scan/[sessionId]

**响应 (processing)**
```json
{
  "sessionId": "scan_01JXXXXX",
  "status": "processing",
  "progress": 65,
  "stageText": "📚 匹配欧美法规库..."
}
```

**响应 (ready)**
```json
{
  "sessionId": "scan_01JXXXXX",
  "status": "ready",
  "progress": 100,
  "stageText": "✅ 完成",
  "result": { ... }
}
```

**响应 (failed)**
```json
{
  "sessionId": "scan_01JXXXXX",
  "status": "failed",
  "progress": 20,
  "stageText": "扫描失败",
  "error": "..."
}
```

## 6. 风险点定义

### Severity (严重程度)
| 值 | 含义 | 视觉表现 |
|-----|------|----------|
| critical | 必须整改 | 红色火焰 🔥 |
| warning | 建议整改 | 橙色火焰 🔥 |
| info | 仅供参考 | 灰色火焰 🔥 |

### FlameLevel (火焰级别)
| 值 | 视觉效果 |
|-----|----------|
| 1 | 小火苗 |
| 2 | 中火 |
| 3 | 大火 |
