## 尚需调整，按优先级

### P0：法规材料与报告可靠性

1. RoHS 查看页多个条款显示同一段 KB 摘要，不能作为逐字原文。应补齐逐条权威原文、来源版本和校验记录，再宣称“已核验”。
2. 修订报告正文涉及三个法规主题，但结构化引用仅一条。应统一正文引用与引用列表，不能只因有一个可打开的链接就视为报告有充分依据。
3. 正文仍可能将“资料未提交”写成“CE 无效”“严禁上市”等强结论，而结构化清单只写待补证、没有对应风险项。需要统一事实、适用性、待证据与法律判断，阻止跨越证据的确定断言。

### P1：结果解释与闭环

4. 充电器本体仍被要求补“外置适配器”，且“没有可见缺陷”落到待确认；应进一步完善检查项的条件适用规则。
5. 说明书/参数摘要上传成功不意味着所有待办能自动关闭；需明确哪条新增证据解决了哪项请求，并展示修订前后变化。
6. 完整报告与文件中仍存在风险等级换算分、模型估算排期；需要统一解释其来源，避免被理解为认证评分或承诺工期。
7. 结果页有重复的图片、清单、补证列表；应在数据契约稳定后合并，减少滚动距离。英文模式中的模型原始描述仍可能混合语言。

### P2：剩余验收

8. 在常规浏览器完成 PDF / DOCX / 证据包 / MD / CSV 的实际保存与排版检查；在最新实现下分别完整复验小米和 LEGO。
9. 视口切换曾出现浏览器截图残影，重新加载后恢复。截图仅用于局部交互记录，不据此承诺全站像素级验收。
