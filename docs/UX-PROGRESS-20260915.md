# 前端体验优化进展 · 2026-09-15

## 已实施

1. 上传页：提高表单面板不透明度和说明文字对比；样例区移到预览区之前；首屏增加跳转样例链接。可选产品问题默认折叠，显示已填写数量。
2. 样例载入：保留三张图片与可选参数摘要流程；加载成功自动回到表单并聚焦，提示在表单顶部显示。切换语言时同步提示；用户条件声明使用稳定的中文选项值，避免切换语言丢失选中状态。
3. 图像预览：主图使用 contain 保留完整画面；取消滚轮切图，避免正常滚页时误换图片；修复更换一张图片会释放其他图片对象 URL 的问题。
4. 手机操作：显示中英文切换；扩大部分控件点击区域；增加焦点样式；返回图标补充可访问名称。市场选择增加 aria-pressed 与明显选中边框，默认欧盟。
5. 结果恢复：加载、成功、失败状态分开。错误时显示重新加载和返回上传；区分凭证失效、未找到、服务故障；存储已满不阻断成功结果，损坏缓存回退到请求。
6. 比赛范围：利润卡片、图片上的报价、利润报告预览及导出入口隐藏；利润直链跳转合规结果，利润报告 API 返回功能不可用。底层金融实现保留。
7. 用语：等待页和报告入口聚焦观察、法规、整改；证据百分比明确指有位置和法规关联的问题占比，不代表合规通过率。
